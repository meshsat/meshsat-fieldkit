# L4-E9: the Layer 5 handover of the selected power architecture (MESHSAT-1357, 1 October 2026; round 2 and the update round, 2 October 2026)

Prototype design. **Drafts for Layer 5 only:** this record edits neither `v2/ecad/tools/pcb_interfaces.yaml` nor
`v2/docs/HW-FW-CONTRACT.md`. Each entry names the contract to write or amend, the text proposed, the interface rows of
`l4e9_power_path.out` (section 4) it rests on and its state. The figures are the ones that output prints; where a row is
PENDING on another task the entry says so and that part of its text waits (none since L4-E7R was accepted). `l4e9_power_path.py` reads this table (out 10) and refuses an entry that
names an interface row the reconciliation does not print. The update round (2 October 2026) carries the accepted results of
L4-E11 (the selected vehicle entry, the interconnect, U-04's rules: LH-01, LH-03, LH-07, LH-08, LH-10) and L4-E12 (the margin
hold and the SGP41's shutdown: LH-11). Round 7 (3 October 2026, Layer 9's L9P-F01): LH-12 and LH-04's pointer to decision D-11's own basis.
Round 8 (4 October 2026): LH-12 now K4's off-list with the fans, the floors staying REQ-018's pass lines (round 7's raised
floor withdrawn as a correction); LH-04 on the final drafts. Update round 3 (L4-E13, U-03 a downstream unit selection) amends LH-02: J_SOLAR's
rating is a property of the existing interface IF-EXT-DC (its `current.solar`), whose current envelope changes to PANEL-ACC's
three cases; no interface is created, so no new row is added.
